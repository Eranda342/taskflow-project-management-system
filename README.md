# TaskFlow

TaskFlow is a real-time full-stack Project Management System designed to help teams create projects, organize tasks, assign work, collaborate, and monitor project progress.

## Technology Stack

### Frontend
- React
- Vite
- Axios
- React Router
- Socket.IO Client

### Backend
- Node.js
- Express.js
- Socket.IO
- JWT
- bcryptjs

### Database
- MongoDB
- Mongoose

### Testing
- Jest
- Supertest

### DevOps
- Git
- GitHub
- GitHub Actions

## Project Structure

- `frontend/` - React frontend
- `backend/` - Node.js backend
- `docs/` - diagrams/testing documentation
- `.github/` - CI/CD workflow configuration
