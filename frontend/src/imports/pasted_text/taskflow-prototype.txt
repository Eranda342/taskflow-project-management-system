==================================================
PRODUCT
==================================================

Product name:

TASKFLOW

Description:

TaskFlow is a collaborative project management and task tracking platform.

It allows organizations and teams to:

- Create and manage projects
- Add project members
- Create and assign tasks
- Track task progress
- Manage task priorities
- Comment on tasks
- Receive notifications
- Collaborate in realtime
- Monitor project progress
- Manage users
- View platform analytics

The backend/API already exists.

The frontend design MUST therefore be structured like a real React application consuming an existing REST API and Socket.IO realtime API.
